# Internship Job Analytics Dashboard

## Project Overview

This project analyzes internship job postings using an interactive Tableau dashboard and a custom HTML/CSS landing page. It provides multiple analytical views with filters for exploring hiring trends, salary distribution, company insights, qualifications, and geographic opportunities.

## Features

- Interactive dashboard navigation
- Landing page with links to all analysis tasks
- Tableau Public visualizations
- Multiple filters for dynamic analysis
- Responsive web interface

## Tools & Technologies

- Tableau Public
- HTML5
- CSV Dataset
- Netlify

## Dataset

The dataset contains internship/job posting information including:

- Company Name
- Company Size
- Job Title
- Salary Range
- Country
- Work Type
- Qualifications
- Experience
- Job Portal
- Preference
- Job Posting Date

## Dashboard Tasks

### Task 1 – Preference vs Work Type
Analyzes internship preferences based on work type after applying salary and company size filters.

### Task 2 – Company Size vs Company
Compares company size with company names using a scatter plot after applying multiple filters.

### Task 3 – Work Type Salary Distribution
Visualizes salary distribution using a box-and-whisker plot after applying the required filters.

### Task 4 – India vs Germany Job Comparison
Compares internship opportunities between India and Germany.

### Task 5 – Top 10 Companies Treemap
Displays leading companies using a treemap visualization.

### Task 6 – Qualification Drilldown Map
Shows qualification-based opportunities using an interactive geographic map.

## Note

The internship instructions mention filtering between **3 PM and 5 PM IST**. The provided dataset does **not contain any time or timestamp column**, so this condition could not be implemented. All other required filters were applied successfully.
